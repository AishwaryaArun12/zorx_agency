# ZORX — Digital Marketing Agency, Dubai

One-page scrolling site for the ZORX web developer test. Built with Next.js, GSAP ScrollTrigger, and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy (GitHub + Vercel)

Requires GitHub CLI (`gh auth login`) and Vercel (`npx vercel login`).

```powershell
cd C:\Users\user\zorx-agency
.\deploy.ps1
```

Or import the folder at [vercel.com/new](https://vercel.com/new).
